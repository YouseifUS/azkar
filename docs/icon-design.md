# Launcher icon

Final asset: `assets/icon/adhkar_icon.png`.

Created with the built-in image generation tool, using the user's moon and sunrise images as style references. Android launcher variants are bundled under `android/app/src/main/res`; no icon-generation package or SDK is required to build the application. The references themselves are not redistributed in this repository.

## Final generation prompt

Use case: logo-brand. Create a single finished Android launcher icon for an Arabic morning and evening Adhkar app. Reference images: first attached half-moon.png is a STYLE/reference for its clean crescent and simple stars; second attached sun.png is a STYLE/reference for its rising sun with a low horizon. Combine these into ONE balanced memorable symbol: a warm gold crescent holding a small rising golden sun with a few restrained rays, a fine horizon line underneath and one small four-point star above. Flat vector-like geometric artwork, refined Islamic elegance, antique deep green (#183E35) full-bleed background, pale ivory and rich antique gold details, crisp edges, strong silhouette readable at 48px. Square 1024x1024 canvas. Center all foreground artwork in the central 60% safe area for Android adaptive cropping. Background fills every edge, NO rounded corners, NO outer circle frame, NO text, NO lettering, NO mockup, NO extra icons. Only ONE icon.
